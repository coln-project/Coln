# Coln compiler Wasm library

This package can be compiled with the [GHC WebAssembly backend](https://downloads.haskell.org/ghc/latest/docs/users_guide/wasm.html) to produce a [WASI reactor module](https://github.com/WebAssembly/WASI/blob/wasi-0.1/application-abi.md#current-unstable-abi). The JavaScript entry points and their TypeScript declarations are derived from the Haskell types by [`wasm-bindgen-hs`](https://github.com/georgefst/wasm-bindgen-hs), and `just npm-package` turns the whole thing in to an NPM package under `_build/npm/coln-compiler`. See [the compiler demo](../../examples/compiler-demo) for how to consume that package; it can be launched with `just examples/serve-web-compiler` from the project root. All necessary tools, including a Wasm-targeting GHC and Cabal, are provided by this repository's top-level Nix shell.
