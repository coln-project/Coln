\section{Introduction}

The SIR (separated intermediate representation) for Coln is an intermediate stage between the core language (which is theory-of-signatures style) and the FLIR (which is relational). Unlike the core language, SIR is simply-typed, but unlike FLIR we still have functions and composite types (e.g. tuples).

This document introduces the theory behind SIR.
